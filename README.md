# ExportYor.AI

AI yordamida bojxona stavkalari, logistika narxi va eksport hujjatlarini tayyorlaydigan Next.js ilova.

## Development

Node.js 18+ kerak.

```sh
npm install
npm run dev
```

Brauzerda [http://localhost:3000](http://localhost:3000) ochiladi.

```sh
npm run build
npm start
```
